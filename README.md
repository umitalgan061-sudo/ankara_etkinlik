# Ankara Etkinlik Toplayıcı

Ankara etkinliklerini farklı kaynaklardan birleştiren, Node.js tabanlı açık bir başlangıç projesi.

> Depo başlangıçta boş olduğu için proje iskeleti sıfırdan kurulacaktır. API anahtarları hiçbir zaman kaynak koda yazılmamalıdır; `.env` dosyası kullanılmalıdır.

Geliştirme dalında API sunucusu, kaynak bağlayıcıları, etkinlik normalizasyonu ve basit bir web arayüzü hazırlanacaktır.

Ayrıntılı kurulum ve kaynak listesi, entegrasyon dosyaları eklendikçe bu belgeye eklenecektir.
